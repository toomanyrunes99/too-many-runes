# Too Many Runes - Changelog

## 3.2.03

- **Item stacks:** the different forms of an item now share one picture with a number on it. Click it to unfold the rest. This covers doses and charges, augmented, dyed and broken versions, upgrades (+ 1 to + 5, Mk. 1 to Mk. 5) and stages, such as the Eternal magic orbs.
- **Made in the backpack:** items you can make without a station show "Made in: Backpack". Search them with `@backpack`.
- **Compost:** see what goes in a compost bin and which compost it makes, with `@compostable`, `@supercompostable` and `@ultracompostable`.
- **Quest items:** search with `@quest`, or `@quest` plus a quest's name. The info box shows which quest an item is from.
- **New search words:**
  - item kinds: `@ore`, `@bar`, `@log`, `@fish`, `@herb`, `@seed`, `@gem`, `@rune`;
  - filters: `@f2p`, `@members`, `@ge`, `@untradeable`;
  - right-click options: `@teleport`, `@bury`, `@read` and more.
- **More station pictures:** the small crafting stations and Aggie now have pictures (`@aggie`).
- **Less clutter:** more junk is hidden automatically, including Dungeoneering copies, Twitch drops, "dummy" items and pickpocket guides.
- **Smoother:** typing in the search box no longer lags, and the mouse wheel down now goes to the next page.
- **Lighter:** the plugin uses about 50-60 MB of memory instead of about 250 MB. It loads faster, and reloading no longer slows the game down.
- **Fixes:**
  - long debug names wrap instead of being cut off;
  - "Hide junk" updates the open item straight away;
  - "Reset to default" now says so in the console;
  - the right-click entries can never become the left-click action.
